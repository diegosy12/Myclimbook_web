# Registro de tutoría

Este documento registra el seguimiento semanal del proyecto: horas dedicadas, acuerdos, avances, bloqueos y siguiente paso.

## Formato de registro

Cada semana añade una entrada con este formato:

```markdown
### Semana [X] - [Fecha]

**Horas dedicadas**: [X]h

**Avances**:
- [Describir lo que has hecho]

**Bloqueos**:
- [Problemas encontrados, si los hay]

**Acuerdos con el tutor**:
- [Decisiones tomadas]

**Siguiente paso**:
- [Qué vas a hacer la próxima semana]
```
